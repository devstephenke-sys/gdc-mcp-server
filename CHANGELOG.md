# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-12

### Added
- Initial release of GDC MCP Server
- Async GDC API client with full endpoint coverage
- MCP server implementation for Model Context Protocol
- Support for projects, cases, files, and annotations
- Molecular data queries (SSMs, CNV, expression, methylation)
- Manifest generation and data download
- Controlled-access data support with token authentication
- Comprehensive documentation with examples
- CI/CD with GitHub Actions
- Test suite with pytest
- Code quality tools (ruff, black, mypy)
